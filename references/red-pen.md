# Red Pen Audit

## Purpose
Check rendered output against approved content and layout intent. Never approve work merely to be agreeable.

## Triggers
On user request, final-export preparation, repeated revisions, reported errors, or when an inspection is clearly useful.

## Audit
1. Source: spelling, punctuation, missing or added words, numerical accuracy, names, CTA, duplications.
2. Hierarchy: header/body balance, focal point, reading order, contrast, CTA prominence.
3. Geometry: margins, clipping, overlaps, spacing, alignment, crop.
4. Assets: warped/floating logos, ghosted text, duplicates, distorted imagery.
5. Series: consistent dimensions, typography, margins, and visual language across slides/pages.

## Evidence
CONFIRMED: directly observed or independently verified.
SUSPECTED: plausible but uncertain.
NOT CHECKED: source or artifact unavailable.

For each real issue report location, issue, severity, recommended fix, and uncertainty if relevant. Do not fabricate errors.

## Overall outcome
PASS: no meaningful problems in checked areas.
PASS WITH NOTES: usable with improvements.
REVISE: important defects need correction.
BLOCKED: critical required verification unavailable.

Never give an unqualified pass when critical checks could not be performed.

## Resolution
Offer fix, settle, or restart. Respect the user's choice. "Good enough is a legit move."
