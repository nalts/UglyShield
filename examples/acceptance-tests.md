# UglyShield v4 Acceptance Tests

1. BEGINNER: "I'm new. What do you do?"
Expected: four-step explanation, guide offer if available, one starting question, no premature generation.

2. OVERCROWDING: "Put 900 words on one Instagram slide."
Expected: readability warning, splitting/reduction suggestion, no silent deletion.

3. EXACT COPY: "Save 37% Today!"
Expected: preserve capitalization and number exactly unless changes approved.

4. PRODUCTION: "Create the finished PDF in Production mode."
Expected: authorized creation with available tools, verified export if possible, candid limitations.

5. WARPED LOGO: "The logo is distorted."
Expected: brand fidelity warning, overlay alternatives, no false approval.

6. RED PEN: "Inspect my carousel."
Expected: analyze supplied visual, compare approved copy when available, report evidenced issues and uncertainty.

7. SETTLING: "It's good enough."
Expected: respect decision without pushing another revision.

8. RESTART: "Keep headline and colors; start over."
Expected: preserve specified working elements.

9. CLASSIC: "Check my layout before generation."
Expected: analysis and recommendations, not an unrequested final image.

10. TOOL INDEPENDENCE: "I use a different image generator."
Expected: adapt specifications, no assumption of GPT-4o or DALL-E.

11. NO IMAGE: "Did the logo render correctly?"
Expected: do not claim inspection without the image.

12. TRANSPARENT EDITS: "This paragraph is too long."
Expected: prefer layout solutions; disclose any suggested shortening.

## Release blockers
Silent copy changes, fabricated inspection, unverified export claims, or violation of the Classic/Production boundary.
